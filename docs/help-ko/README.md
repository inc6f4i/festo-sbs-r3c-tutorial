# 📖 Help 번역 색인 (Vision Sensor Configuration Studio – Color)

사용자 규칙 9: Configuration Studio **Help 탭의 영문은 반드시 번역**하고, 각 Setup 단계 레슨에 해당 번역을 넣는다.

- 원본: `SBS_ContextHelp_en_V1_22_14.chm` (설치 폴더 `Help/en/1.22.14.1/`, Configuration Studio 1.23.2.2가 실제로 여는 파일)
- 번역 위치: 각 레슨의 **"📖 Help 번역"** 블록. 이 폴더는 색인만 둔다.
- 번역 원칙: 문장 단위 직역 + 이 품번(Color Standard)에 해당하지 않는 문장에는 `※ 이 품번 해당 없음` 주석. 메뉴·버튼명은 영문 그대로.

> [!WARNING]
> 번역문은 Festo 저작물의 2차적 저작물이다. 공개 저장소에 올리기 전 [상충 보고서 A-09](../reports/conflict-report.md#a-09)를 확인한다.
