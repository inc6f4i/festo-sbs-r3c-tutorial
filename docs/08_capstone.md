# Module 08 — 최종 프로젝트: 캡 조립품 외관 검사 셀

> 지금까지 배운 것을 한 잡에 모은다: **위치 추적 + 조명/전처리 + 복수 검출기 + 잡 판정 + 24 V 출력 + NG 이미지 저장**.

## 🎯 목표
1. 결함 4종 이상을 판별하는 검사 잡을 **혼자 설계·구현**한다.
2. 합격 기준(정확도, 사이클 타임, 위치 편차 허용)을 **수치로 증명**한다.
3. 백업 파일·결과표·시연 영상·포트폴리오 요약을 남긴다.

## 1. 시나리오

3D 프린터로 만든 **본체(밝은 색) + 캡(빨강)** 조립품이 작업대(컨베이어 대용) 위에 놓인다. 작업자가 부품을 놓으면 버튼(핀 03)으로 트리거한다. 센서는 판정해 **OK면 핀 07에 24 V, NG면 핀 12에 24 V(배출 신호)** 를 내고, NG 이미지는 PC에 남긴다.

| 시료 | 만드는 법 (3D 프린터) | 수량 |
|---|---|---|
| OK | 본체 + 빨간 캡(지름 D) | 1–3개 |
| NG-1 캡 없음 | 본체만 | 1 |
| NG-2 캡 색 틀림 | 본체 + 파란(또는 주황) 캡 | 1 |
| NG-3 캡 크기 틀림 | 본체 + 빨간 캡 지름 D+1 mm, D−1 mm | 2 |
| NG-4 위치 편차 초과 | OK 시료를 허용 영역 밖에 놓기 / 뒤집어 놓기 | (OK 시료 사용) |
| NG-5 (선택) 이물 | 본체 위에 검은/색 점(마커·작은 출력물) | 1 |

> 치수는 Module 00에서 정한 FOV에 맞춘다. 캡 지름 D는 화면에서 **최소 60 px** 이상이 되게(예: mm/px 0.077이면 D ≥ 5 mm).

## 2. 결함–검출기 설계표

| 결함 | 검출기 / 기능 | 판정 근거 | 왜 이 검출기인가 | 대체 |
|---|---|---|---|---|
| NG-4 위치·자세 이상 | Alignment › Contour detection | 정렬 점수 < Threshold 또는 검색 영역 밖 | 360° 회전에서도 추종하는 유일한 정렬(Help: scalignmentedit) | — |
| NG-1 캡 없음 | D1 **Contrast** (캡 부위) | Contrast < min | 캡 있음/없음의 명암 섞임 차이, 2 ms | D2 면적 % ≈ 0으로도 잡힘 |
| NG-2 캡 색 틀림 | D2 **Color area** (HSV, 빨강 H 범위) | 면적 % < min | 색만 다른 경우 Contrast로는 구분 안 됨 | — |
| NG-3 캡 크기 틀림 | D3 **Color area** (같은 색 범위, 면적 % min/max 또는 Object size) | 면적 % 가 [min, max] 밖 | 이 품번은 Caliper 없음 → 면적 비례 Go/No-Go (04-3) | D3 대신 경계 띠 Contrast 2개 |
| NG-5 이물 (선택) | D4 **Color area** (이물 색 범위, 본체 면) | 면적 % > max | 본체 색과 다른 색 점의 면적 | — |

> [!WARNING]
> **V-01**(잡당 검출기 최대 수) 결과가 "2"라면 **설계 B**를 쓴다:
> D1 Contrast(캡 없음) + D2 Color area(빨강 면적 % **min과 max를 둘 다** 설정 → 색 틀림·크기 큼/작음을 한 검출기로) — 이물(NG-5)은 생략. 이 결정을 결과 보고서에 쓴다.

## 3. 판정·출력 설계

| 출력 | 핀 | 논리식 (설계 A) | Reset signal | 비고 |
|---|---|---|---|---|
| Overall job result | — | `D1&D2&D3&D4` | — | 통계·아카이빙·레코더 기준 |
| OK | 07 BK | `D1&D2&D3&D4` | Change on result | 24 V = 양품 |
| NG (배출) | 12 RDBU | `!(D1&D2&D3&D4)` | Result Duration 500 ms | 24 V 펄스 = 배출 |
| 캡 검출 (디버그) | 08 GY | `D1` | Change on result | 선택 |
| Ready / Valid | 04 / 11 | 고정 | — | 선택: 표시등 |

정렬 실패 시 정렬을 따르는 검출기 결과가 어떻게 되는지 ⚠️ 확인하고(정렬 실패 → 검출기 실패 → 잡 NG가 기대), 아니면 논리식을 고친다.

## 5. 합격 기준

| 항목 | 기준 | 측정 방법 |
|---|---|---|
| OK 판정 정확도 | **20/20 OK** (과검출 0) | OK 시료를 허용 영역 안 임의 위치·각도에 20회 놓기 |
| NG 판정 정확도 | 결함 유형별 **10/10 NG** (미검출 0) | NG-1~NG-4(+5) 각 10회 |
| 결함 구분 | NG 원인 검출기가 설계표와 일치 ≥ 90 % | Result 탭에서 실패한 검출기 기록 |
| 검출기 마진 | 모든 검출기 ≥ 15 %p | 04 정의 |
| 사이클 타임 | Statistics **Maximum execution time ≤ 150 ms** | Start sensor, 트리거 50회 |
| 위치 편차 허용 | X·Y **±5 mm**, 회전 **±180°** 안에서 OK 유지 | 03 실험 방식 |
| 출력 | OK → 핀 07 ≥ 22 V / NG → 핀 12 펄스 ≥ 22 V, 반대 핀 ≤ 1 V | 멀티미터 |
| NG 이미지 | 저장 파일 수 = NG 트리거 수 | 아카이빙 폴더 |

> 150 ms는 데이터시트 typ. 값 합(위치 추적 30 + Contrast 2 + Color area 30×3 ≈ 122 ms)에 여유를 둔 출발값이다. 실측 후 근거와 함께 조정한다.

## 7. 고장 주입 (시연 영상에 포함)
- 실내등 끄기 → 판정 유지 확인 (조명 설계 증명)
- 시료를 허용 영역 경계(±5 mm)와 밖(±10 mm)에 놓기 → OK / NG 구분
- 버튼 연타 → Count와 판정 수 일치(채터링 대책)
- 전원 재투입 → 13 s 뒤 같은 잡으로 자동 운전(플래시 저장 확인)
